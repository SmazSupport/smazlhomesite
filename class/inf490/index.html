Network Client Inventory & Interface Monitoring Tool

Problem: A hotel management company remotely operates the network at a branded hotel property in Houston, TX. The IT team has no centralized view of devices on the network, no rogue device detection, and no change history for troubleshooting — everything requires manual digging through the Meraki dashboard.

Solution: Custom monitoring tool that pulls client, device, interface, and VLAN data from the Cisco Meraki Dashboard API into a Python backend and SQL database, surfaced in a web dashboard with live inventory, rogue device detection, change tracking, and automated alerts.

Role: Sole developer and project owner — discovery, requirements, scope, architecture, build, testing, documentation, and client communication.

Status: In progress. Goal is a real-time inventory replacing manual lookups, automated rogue detection, change history for troubleshooting, and cross-boundary network visibility.
